# Customer Support Intent Annotation & Data Quality Pipeline

## Project summary

An end-to-end AI training-data quality project using a 300-record stratified sample from the Bitext Customer Service Tagged Training Dataset.

## Problem

Customer-support AI systems depend on consistently labeled and reviewed training data. Even when a dataset already contains labels, quality assurance is required to identify ambiguous examples, inconsistent classifications and language variations.

## What I built

- representative dataset sampling
- annotation/review guidelines
- independent intent review fields
- ambiguity and human-review flags
- confidence scoring
- Python validation
- SQL quality analysis
- reproducible QA reporting

## Technology

Python, Pandas, Hugging Face Datasets, SQLite, SQL, Jupyter, Git/GitHub.
